Pré-requisitos

Tudo é instalado no desktop Windows que fará o build. A maior parte vai no seu usuário comum; só recursos de sistema (como o OpenSSH Server) pedem Administrador. Prefira sempre as versões de download oficiais.

Se preferir um gerenciador de pacotes, winget instala quase tudo isto sem baixar instaladores à mão. Os comandos winget aparecem em abas ao lado de cada ferramenta.

1 · Node.js Terminal comum

Use a versão LTS. Ela traz o npm e o npx usados pelo bridge e pelo Expo.

PowerShellcomum
winget install OpenJS.NodeJS.LTS

Baixe o instalador LTS em nodejs.org e conclua o assistente (mantenha a opção de adicionar ao PATH).

Feche e reabra o terminal e confirme:

PowerShellcomum
node -v
npm -v

2 · JDK 17 Terminal comum

Esta versão do app usa Expo (SDK recente) + React Native, que exigem o JDK 17. Versões mais novas costumam quebrar o Gradle. Use uma distribuição confiável como Eclipse Temurin (Adoptium) ou Microsoft Build of OpenJDK.

PowerShellcomum
winget install EclipseAdoptium.Temurin.17.JDK
PowerShellcomum
winget install Microsoft.OpenJDK.17

Baixe o JDK 17 em adoptium.net (pacote .msi para Windows x64) e instale.

Definir JAVA_HOME

O Gradle encontra o Java por essa variável. Defina-a no escopo do usuário (não precisa de Admin) e ajuste o PATH:

PowerShellcomum
# Ajuste o caminho para a pasta real onde o JDK 17 foi instalado
$jdk = "C:\Program Files\Eclipse Adoptium\jdk-17"
[Environment]::SetEnvironmentVariable("JAVA_HOME", $jdk, "User")
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$jdk\bin", "User")

Reabra o terminal e confirme a versão 17:

PowerShellcomum
java -version

Se o java -version mostrar uma versão diferente de 17, há outro JDK na frente no PATH. Corrija o JAVA_HOME e a ordem do PATH antes de seguir — quase todo erro de Gradle começa aqui.

3 · Android SDK (sem Android Studio) Terminal comum

Você não precisa da IDE completa — só das command-line tools, do adb (platform-tools), das build-tools e de uma plataforma. Esse conjunto leve já compila e instala o APK.

1

Baixe o pacote “Command line tools only” para Windows na seção Command line tools da página de downloads do Android Studio.

2

Organize a pasta no layout que o sdkmanager espera — ele precisa ficar em cmdline-tools\latest:

estrutura esperada
<ANDROID_HOME>\
  cmdline-tools\
    latest\
      bin\   lib\   NOTICE.txt   source.properties

Escolha uma pasta para o SDK (ex.: %LOCALAPPDATA%\Android\Sdk), e mova o conteúdo extraído para cmdline-tools\latest.

3

Defina ANDROID_HOME e adicione as ferramentas ao PATH (escopo de usuário, sem Admin):

PowerShellcomum
$sdk = "$env:LOCALAPPDATA\Android\Sdk"
[Environment]::SetEnvironmentVariable("ANDROID_HOME", $sdk, "User")
[Environment]::SetEnvironmentVariable("ANDROID_SDK_ROOT", $sdk, "User")
$tools = "$sdk\cmdline-tools\latest\bin;$sdk\platform-tools"
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$tools", "User")
4

Instale os pacotes essenciais e aceite as licenças (passo obrigatório — sem isso o build falha):

PowerShellcomum
# Reabra o terminal para o PATH valer
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
sdkmanager --licenses

Use a plataforma/build-tools que o projeto pedir (verifique mobile/android após o prebuild). Se o Gradle reclamar de uma versão ausente, rode sdkmanager "platforms;android-<API>" "build-tools;<VERSAO>" com os valores indicados.

5

Confirme que o adb está disponível:

PowerShellcomum
adb version

4 · OpenSSH (cliente e servidor)

O cliente dá o ssh-keygen e permite testar o túnel. O servidor (sshd) é o que recebe o túnel vindo do celular — é o único serviço que ficará alcançável de fora.

Cliente OpenSSH Admin se faltar

No Windows 10/11 ele geralmente já vem ativo. Verifique primeiro:

PowerShellcomum
ssh -V

Se não existir, habilite como Administrador:

PowerShellAdministrador
Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

Servidor OpenSSH Administrador

PowerShellAdministrador
# Instalar o componente
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

# Iniciar e deixar em inicialização automática
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic

A configuração de segurança do sshd (usuário dedicado, chave, hardening) vem no capítulo 3. Por ora basta ter o serviço instalado e rodando.

5 · Preparar o aparelho Android

O APK é instalado por cabo USB. Ative o modo desenvolvedor no celular:

  1. Em Configurações → Sobre o telefone, toque 7× em Número da versão para liberar as Opções do desenvolvedor.
  2. Em Opções do desenvolvedor, ligue a Depuração USB.
  3. Conecte o cabo e, no celular, autorize a chave de depuração do computador.

Confirme que o aparelho aparece como device (e não unauthorized):

PowerShellcomum
adb devices

6 · Git e o repositório Terminal comum

PowerShellcomum
winget install Git.Git

Baixe em git-scm.com e instale.

Clone o repositório do app na pasta que você vai chamar de <PROJECT_ROOT> daqui em diante.
