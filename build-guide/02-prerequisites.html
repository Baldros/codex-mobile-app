Chapter 2

Prerequisites

Everything is installed on Windows desktop which will do the build. Most of it goes in your common user; only system resources (like installing WireGuard) require Administrator. Always prefer official download versions.

If you prefer a package manager, winget installs almost all of this without downloading installers by hand. The commands winget appear in tabs next to each tool.

1 · Node.js Common terminal

Use the LTS version. She brings the npm and the npx used by bridge and Expo.

PowerShellcommon
winget install OpenJS.NodeJS.LTS

Download the LTS installer from nodejs.org and complete the wizard (keep the option to add to PATH).

Close and reopen the terminal and confirm:

PowerShellcommon
node -v
npm -v

2 JDK 17 Common terminal

This version of the app uses Expo (recent SDK) + React Native, which require JDK 17. Newer versions often break Gradle. Use a trusted distribution like Eclipse Temurin (Adoptium) or Microsoft Build of OpenJDK.

PowerShellcommon
winget install EclipseAdoptium.Temurin.17.JDK
PowerShellcommon
winget install Microsoft.OpenJDK.17

Download JDK 17 from adoptium.net (package .msi for Windows x64) and install.

Set JAVA_HOME

Gradle finds Java by this variable. Define it in the scope of user (no Admin needed) and adjust the PATH:

PowerShellcommon
# Adjust the path to the actual folder where JDK 17 was installed
$jdk = "C:\Program Files\Eclipse Adoptium\jdk-17"
[Environment]::SetEnvironmentVariable("JAVA_HOME", $jdk, "User")
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$jdk\bin", "User")

Reopen the terminal and confirm the version 17:

PowerShellcommon
java-version

If the java-version show a version other than 17, there is another JDK in front in the PATH. Correct the JAVA_HOME and the PATH order before following — almost every Gradle error starts here.

3 · Android SDK (without Android Studio) Common terminal

You don't need the full IDE — just the command-line tools, from adb (platform-tools), build-tools and a platform. This lightweight suite already compiles and installs the APK.

1

Download the “Command line tools only” package for Windows in the section Command line tools from the page Android Studio downloads.

2

Organize the folder in the layout that the sdkmanager wait — he needs to stay in cmdline-tools\latest:

expected structure
<ANDROID_HOME>\
  cmdline-tools\
    latest\
      bin\ lib\ NOTICE.txt source.properties

Choose a folder for the SDK (e.g.: %LOCALAPPDATA%\Android\Sdk), and move the extracted content to cmdline-tools\latest.

3

Define ANDROID_HOME and add the tools to PATH (user scope, no Admin):

PowerShellcommon
$sdk = "$env:LOCALAPPDATA\Android\Sdk"
[Environment]::SetEnvironmentVariable("ANDROID_HOME", $sdk, "User")
[Environment]::SetEnvironmentVariable("ANDROID_SDK_ROOT", $sdk, "User")
$tools = "$sdk\cmdline-tools\latest\bin;$sdk\platform-tools"
[Environment]::SetEnvironmentVariable("Path", "$env:Path;$tools", "User")
4

Install the essential packages and accept the licenses (mandatory step — without this the build fails):

PowerShellcommon
# Reopen the terminal for the PATH to take effect
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
sdkmanager --licenses

Use the platform/build-tools that the project requires (check mobile/android after the prebuild). If Gradle complains about a missing version, run sdkmanager "platforms;android-<API>" "build-tools;" with the indicated values.

5

Confirm that the adb is available:

PowerShellcommon
adb version

4 · WireGuard (desktop and phone)

WireGuard is what carries the connection from the phone to your machine. The desktop is the server; the phone is a peer. No paid VPN service is involved.

Desktop Administrator

PowerShellAdministrator
winget install --id WireGuard.WireGuard -e

Confirm the command-line tool is present:

PowerShellcommon
& "C:\Program Files\WireGuard\wg.exe" --version

Phone

Install the official app from the store:

Android
Name:      WireGuard
Publisher: WireGuard Development Team
Package:   com.wireguard.android

Key generation, peer configuration and the tunnel itself come in chapter 3. For now, just have both installed.

OpenSSH is no longer required

Earlier versions of this guide installed OpenSSH Server to receive an SSH tunnel from the phone. That is gone. If you followed an older version and no other project on the machine needs it, consider turning sshd off — leaving it running keeps an extra service exposed for nothing.

5 · Prepare the Android device

The APK is installed via USB cable. Activate developer mode on your phone:

  1. In Settings → About phone, tap 7x Version number to release the Developer Options.
  2. In Developer Options, call USB debugging.
  3. Connect the cable and, on the cell phone, authorize the computer's debug key.

Confirm that the device appears as device (and not unauthorized):

PowerShellcommon
adb devices

6 · Git and the repository Common terminal

PowerShellcommon
winget install Git.Git

Download at git-scm.com and install.

Clone the app repository in the folder you will call <PROJECT_ROOT> from now on.
