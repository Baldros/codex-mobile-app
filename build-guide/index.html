Compile Codex Mobile from scratch

An Android client that operates a local Codex CLI session on your desktop, talking to it over a private WireGuard VPN — including on mobile networks. This guide takes you from the empty environment to the installed APK, without opening anything from your machine for the internet.

What will you build

The mobile app is just a operation customer. All power — the Codex CLI, OpenAI login, workspace, and permissions — remains in desktop, which is the trust boundary. The cell phone talks to a Codex Bridge location inside a private WireGuard network, and the only thing reachable from outside is the VPN itself.

Conventions in this guide

The commands use placeholders and environment variables instead of actual values. Always replace the sections between < > for their own values ​​and never write secrets directly to versioned files.

PlaceholderMeans
<PROJECT_ROOT>Folder where you cloned the app repository.
<YOUR_USER>Your development Windows user.
<TUNNEL_NAME>Name you give the WireGuard tunnel on the host. It also names the Windows service.
<HOST_TUNNEL_ADDRESS>The desktop's address inside the private network. Pick a range you do not already use.
<DEVICE_TUNNEL_ADDRESS>The phone's address inside the same network, as a /32.
<WG_PORT>UDP port WireGuard listens on. The only port that may ever reach you from the internet.
<BRIDGE_PORT>TCP port where Codex Bridge listens, bound to the host's tunnel address only. Never forwarded on a router.
Principle that guides everything here

The Codex Bridge binds only to the host's address inside the private network, and is never published. A single UDP port crosses the internet: WireGuard's. That is also why this guide avoids printing real ports, addresses or paths — and recommends you keep yours out of anything you publish.

Common Terminal × Administrator

Good news: the build itself does not require administrator. Node, npm, Expo, Gradle and adb run in a common PowerShell, as long as the variables and PATH are already configured. What do you need Administrator is the one-time system preparation.
